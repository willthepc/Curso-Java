## 🚀 Conhecimentos Técnicos (Java Development)

Atualmente focado no ecossistema Java, desenvolvendo habilidades que abrangem desde a lógica fundamental até frameworks modernos de mercado.

### ☕ Java & Programação Orientada a Objetos
* **Fundamentos:** Lógica de programação, algoritmos e sintaxe Java.
* **POO Avançada:** Classes, atributos, métodos, construtores, sobrecarga e encapsulamento.
* **Pilares da POO:** Herança, polimorfismo, interfaces e composição.
* **Recursos Avançados:** Tratamento de exceções, Generics, Enumerações.
* **Modern Java:** Programação funcional, expressões Lambda e Stream API.
* **Manipulação de Dados:** Estruturas de dados (Arrays e Coleções) e manipulação de arquivos.

### 🛠️ Frameworks & Ferramentas
* **Spring Ecosystem:** Spring Boot, Spring Data JPA e Spring Data MongoDB (NoSQL).
* **Persistência de Dados:** JPA / Hibernate (ORM) e JDBC (SQL).
* **Build & Versionamento:** Maven (Gerenciamento de dependências) e Git/GitHub.
